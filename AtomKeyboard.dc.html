AtomKeyboard
v1 · pastel keyboard mockup · static screens

A full front-end mockup of the gesture keyboard described in the spec, drawn in a muted, dusty pastel palette with raised keycaps. Everything here is a static screen — no live typing engine — so each state the spec calls out is shown as its own frame rather than hidden behind an interaction.

Assumptions I made, flag anything that's wrong: the brand mark on the spacebar reads atom; the vibrant extension tile colors from the spec are re-tinted to deeper pastels so they read as accents rather than fight the keyboard; icons are simple glyphs standing in for a real icon set; and the two Claude themes reuse Claude's own paper/ink/coral values rather than a pastel derivative.

Sections below: tokens, device screens, layers & states, gestures, key height, extension deck, settings, themes.
